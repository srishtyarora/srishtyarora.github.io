# Srishty Arora — Professional Portfolio

A static, single-page professional website built from Srishty's October 2026 academic CV. It highlights epidemiology, quantitative public-health research, applied state epidemiology, selected publications, and professional experience.

## Publish on GitHub Pages

1. Sign in to GitHub and create a **public** repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your actual GitHub username).
2. Choose **Add file → Upload files**, then upload `index.html` from this folder (not the ZIP itself). Commit to the `main` branch.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, `main`, `/ (root)`, then Save.
4. Visit `https://YOUR-USERNAME.github.io/` after GitHub finishes publishing. This can take several minutes.
5. Add the website URL to LinkedIn's contact information and Featured section, and to your CV.

## Privacy and accuracy checks before publishing

- The site intentionally excludes residential street address and telephone number.
- Verify all position descriptions, publication details, and your preferred public contact method.
- LinkedIn is currently the primary public contact link.
- A PhD completed in 2026 is reflected on the site.

## Editing

Edit `index.html` with any text editor, save, and upload the revised file to GitHub to update the live website.
